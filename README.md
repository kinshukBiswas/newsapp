## Clone this project

You can clone this github project using (ensure that git is installed in your computer):

```bash
git clone https://github.com/kinshukBiswas/newsapp.git
```

After cloning (only if _node and npm_ is install, else download it), write the following in your terminal of that folder where it is cloned:

```bash
npm install .
```

otherwise:

```bash
cd "path/to/project/folder/remember/to/replace/this/section/with/that/path"
npm install .
```

to install all the `node_modules` folders.
